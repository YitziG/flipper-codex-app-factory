# Sample Tool

Minimal generated Flipper Zero app from the Codex factory.

This generated app starts, writes a simple log line, and exits. Extend it only after reviewing the Flipper API surface and the safety implications of any hardware-facing behavior.

## Build

```bash
ufbt lint
ufbt
```

## Launch

Review the generated C code before launching on a connected Flipper:

```bash
ufbt launch
```
